# Cleanup of 2026-11-11 (pre-publication)

Owner-approved cleanup before public release: remove Codex-era code no longer used by the maintained path, delete the
old release data, drop the web front end, make machine paths configurable, and add CI. Nothing here edited frozen
data-producing modules (`gitrx_core/spl_parser.py`, `section_groups.py`, `changes.py`, `normalize.py`, `srlc_grade.py`,
`srlc_split.py`, `srlc.py`), evidence, sealed results, grading outputs or raw downloads.

## Recover removed code

Git tag `codex-final` (commit `e0a1082096f82df7699d79ad4b07b8fc2791b0f5`, an ancestor of `main`) contains every removed tracked file.

    git show codex-final:gitrx_backend/web.py                      # one file
    git checkout codex-final -- gitrx_backend/web.py               # restore one file into the tree
    git worktree add ../GitRx-codex-final codex-final              # whole legacy tree

## Method

An import graph (AST, including lazy imports) was built from the maintained entry points: `gitrx_backend.cli`, `mcp`,
`selftest`, `recovery`, `rebuild_names`, `benchmark`, `qualification`, `research`, `selective_install`, `validation_study`,
all of `gitrx_core` (rebuild, srlc*, update jobs, gap repair), `tools/verify_gitrx.py` and `tools/native_research_figures.py`. Every
module reachable from those, and its tests, was kept. Everything else in the tracked packages was removed.
`gitrx_backend/jobs.py` was reduced to the shared ledgered HTTP client and durability helpers that the update jobs and
gap repair import (`HTTP`, `sha`, `atomic`, `sync_body`); its release-cycle `Job` machinery was removed.
